## 1. 设计基调

毛球（原创角色）与整套视觉遵守四个关键词：

- **珊瑚橙**：主行动色与角色主色，温暖但不刺眼；
- **奶油白**：纸面底色，卡片与页面都落在奶油色系上；
- **铅笔线**：描边带轻微手绘感，圆角允许轻微不规则；
- **轻颗粒**：极轻的纸面颗粒纹理，只做质感，不影响可读性。

只借鉴成熟卡牌产品的**揭晓节奏**（期待 → 光迹 → 停稳 → 揭示）与**卡面层级**（稀有度徽标 / 掌握状态 / 内容区 / 证据区），不复刻、不描摹、不导出其任何美术资产。

## 2. 动效时间轴

### 2.1 首页卡池

| 动作 | 参数 |
| --- | --- |
| 卡池切换展开 | 被选中的卡池卡旋转 4–6°（其余回落到 0°），带轻微上浮 |
| 轻压回弹 | `:active` 时缩放到约 0.96，松开后用带一点过冲的缓动（如 `cubic-bezier(.34,1.56,.64,1)`）弹回 |
| 长按开始召回 | 在卡叠上长按 ≥ 450ms 触发；触发后保留“召回 1 张 / 连续召回”按钮作为等价入口 |
| 上拖开始召回 | 上拖位移进入 24–36px 区间即触发；拖动过程中卡叠倾斜 clamp 在 ±4° 以内 |
| 手势取消 | 未达到阈值松手，卡叠在 200ms 内弹回原位，不产生任何副作用 |

### 2.2 召回过场（总时长约 1450ms）

| 阶段 | 时间窗 | 内容 |
| --- | --- | --- |
| 起势 | 0–250ms | 封存卡从卡叠升起，倾斜 ≤ ±4° |
| 光迹 | 250–750ms | 一道按稀有度着色的光迹扫过：R 铅笔灰、SR 珊瑚橙、SSR 暖金；只表达内容潜力，不表达概率 |
| 停稳 | 750–1250ms | 卡面归正、落定，轻微回弹 |
| 亮标 | 1250–1450ms | 稀有度徽标与掌握状态淡入 |
| 进入回忆 | 1450ms | 自动进入回忆卡面；任意时刻可点“跳过过场”直接落地 |

红线：过场中不出现转盘、卡包、十连、概率数字、保底计数或“差点抽到”的伪悬念。

### 2.3 语义揭示

| 动作 | 参数 |
| --- | --- |
| 语义擦开 | 首次唤醒时，承重语义 span 被铅笔涂鸦层覆盖；拖擦覆盖率达到约 45% 后完整揭示，无像素残留 |
| 点击揭示 | 点击（轻点）遮盖区域同样揭示，260ms 内淡入完整语义；键盘 Enter / Space 等价，方向键可分段擦开 |
| 直接揭示 | 始终保留文字按钮入口，服务 VoiceOver 与运动障碍用户 |
| 复现变式 | 后续复现改为判断（对 / 不对）或选择（少量选项），选择后立即给出对错与解释 |

### 2.4 反馈与入册

| 动作 | 参数 |
| --- | --- |
| 三档反馈 | 只有“记得 / 模糊 / 忘记”三个按钮，配色克制（柔绿 / 暖金 / 灰红），无连击、无爆闪 |
| 毛球点击反应 | 点击毛球触发一次 280–420ms 的挤压回弹（squash & stretch），可伴随一句轮换提示 |
| 入册 | 结果页卡片修复上色 + 落入收藏册，一次完成；庆祝只此一次，不循环播放 |
| 下次复习 | 反馈真实写入调度并展示：忘记 → 明天优先，模糊 → 2 天后，记得 → 4 天后（演示数值，正式由调度器决定） |

### 2.5 无假进度

- 禁止假进度条、假百分比、伪造的“加载中”动画；
- 分析等待页只展示真实阶段文案（如“识别画面与文字证据…”）或静态说明；
- 所有等待都必须可被真实完成或真实失败终止。

## 3. 状态机

### 3.1 召回会话状态机

```text
                ┌─────────────┐
                │    pool     │ 今日 Tab：选记忆池、选单张/连续
                └──────┬──────┘
        点击按钮 / 长按 / 上拖 24–36px
                       ▼
                ┌─────────────┐   跳过 / Reduce Motion
                │  summoning  │ ──────────────────────┐
                └──────┬──────┘                       │
              ~1450ms 过场完成                        │
                       ▼                              ▼
                ┌─────────────┐                ┌─────────────┐
                │   recall    │ ◄──────────────│  (直达卡面)  │
                │ masked /    │                └─────────────┘
                │ judgment /  │
                │ choice      │
                └──────┬──────┘
        擦开 ≥45% / 点击揭示 / 直接揭示 / 作答变式
                       ▼
                ┌─────────────┐
                │  revealed   │ 完整语义 + 解释 + 来源证据
                └──────┬──────┘
            记得 / 模糊 / 忘记
                       ▼
                ┌─────────────┐
                │  repaired   │ 掌握状态推进 + 真实下次复习时间
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │  archived   │ 落入记忆收藏册；连续模式由用户手动进入下一张
                └─────────────┘
```

任意时刻退出：回到 `pool`，不记失败、不扣任何东西。`judgment` / `choice` 变式只在卡片已完成首次唤醒后出现；`masked_semantic` 只出现一次。

## 4. Reduce Motion 降级

触发源：`prefers-reduced-motion: reduce` 媒体查询（跟随系统，演示页在我的 Tab 中展示当前状态）。

| 标准行为 | 降级行为 |
| --- | --- |
| 1450ms 召回过场 | 跳过过场，直接落在回忆卡面（≤ 20ms） |
| 卡池 4–6° 展开与回弹 | 仅透明度 / 选中态变化，无旋转位移 |
| 上拖手势倾斜 | 保留手势阈值，取消倾斜动画 |
| 擦开粒子 / 涂鸦剥落 | 遮盖层直接淡出，阈值逻辑不变 |
| 毛球 280–420ms 挤压 | 静态表情切换，无缩放动画 |
| 光迹扫过 | 稀有度徽标直接呈现 |
| 全局滚动与转场 | `animation-duration` / `transition-duration` 收敛到接近 0 |

降级只移除“动”，不移除“态”：状态推进、阈值、结果页和调度完全一样。

## 5. 角色姿态（毛球）

毛球是用户的记忆守护伙伴：奶油白毛发、珊瑚色微光、深青色铅笔描边与轻颗粒阴影。它不发放奖励，只陪伴认知动作。

| 姿态 | 使用场景 | 表现 |
| --- | --- | --- |
| 待机 idle | 今日 Tab 默认 | 缓慢呼吸浮动，周期眨眼 |
| 好奇 curious | 用户切换记忆池 | 头部轻微侧倾（≤ 4°），眼睛睁大 |
| 思考 thinking | 召回过场 / 分析中 | 眼睛看向斜上方，慢速浮动 |
| 被点 boop | 用户点击毛球 | 280–420ms 挤压回弹，轮换一句提示语 |
| 欣慰 glad | 反馈为“记得” | 微笑 + 一次轻微跳起，不循环 |
| 鼓励 steady | 反馈为“模糊 / 忘记” | 平稳点头，文案强调“没有惩罚，只会更早再见” |
| 打盹 sleepy | 空池 / 今日已完成 | 闭眼慢呼吸，提示明天再来 |

实现约束：Web 与 iOS 共用 v0.6 原创透明 PNG 姿态资产；SwiftUI/CSS 只负责缩放、位移、倾斜、粒子与 Reduce Motion 降级。两端都不导入第三方角色素材。

## 6. 反赌博与无社交边界

动效与素材不得越过以下边界：

1. 不制造概率悬念：光迹只表达已定卡片的内容潜力，卡在进入过场前已被调度器选定；
2. 不用递增刺激：没有连抽加速、没有“再来一发”式催促，连续模式每张之间由用户手动推进；
3. 不用损失厌恶：没有倒计时、 streak、保底、错过提示；忘记不降级、不摧毁卡片；
4. 不做社交比较：无排行榜、无分享战绩、无好友资产展示；知识库与收藏册仅自己可见；
5. 不用成就压迫：无签到、无每日任务墙；统计页只展示真实数字；
6. 不用虚假反馈：无假进度、无伪装的“AI 正在努力思考”循环动画；
7. 庆祝克制：单次、短促、可跳过，永远服务“我想起来了”这个认知时刻，而不是“我抽到了什么”。

硬性规则：

- MVP 不引入 Lottie / Rive 及任何动效运行时；
- 不下载或使用授权不清的素材；拿不准就不进仓库；
- 不得宣称使用了未实际导入的素材——登记文档与实际文件、依赖锁定一一对应；
- 角色与卡面默认原创；白名单只覆盖动效依赖、粒子与图标三类补充；
- 借鉴仅限节奏与层级：任何第三方游戏的图、音效、字体、卡面设计都不进仓库。
