## 1. 设计基调

毛球（原创角色）与整套视觉遵守四个关键词：

- **珊瑚橙**：主行动色与角色主色，温暖但不刺眼；
- **奶油白**：纸面底色，卡片与页面都落在奶油色系上；
- **铅笔线**：描边带轻微手绘感，圆角允许轻微不规则；
- **轻颗粒**：极轻的纸面颗粒纹理，只做质感，不影响可读性。

只借鉴成熟卡牌产品的**揭晓节奏**（期待 → 光迹 → 停稳 → 揭示）与**卡面层级**（稀有度徽标 / 掌握状态 / 内容区 / 证据区），不复刻、不描摹、不导出其任何美术资产。

设计检索参考 [Agent UI Atlas](https://github.com/starvingarc/agent-ui-atlas)，组合比例锁定为 50% Kawaii Minimal、30% Hand-Drawn Doodle / Sketch Line Art、20% High-End Soft UI / Fluid Motion。Atlas 只用于提取留白、材质、线条和动效原则；其链接项目、品牌、截图和素材仍受各自许可证约束。

## 2. 动效时间轴

### 2.1 首页与召回入口

| 动作 | 参数 |
| --- | --- |
| 毛球待机 | 8–14 秒最多一次微动作；用户操作、低电量或 Reduce Motion 开启后停止 |
| 轻点毛球 | 280–420ms 情境回应，只改变姿态或提示，不发放奖励 |
| 主入口轻压 | `:active` 时缩放到约 0.97，松开后用可打断弹性缓动回到原位 |
| 上拖 / 等价按钮召回 | 把卡叠上拖 24–36pt，或点击唯一等价按钮；两者进入同一状态，不形成单抽 / 连续双入口；拖动中卡片倾斜 clamp 在 ±4° |
| 手势取消 | 未达到阈值松手，卡叠在 200ms 内弹回，不创建会话、不改变调度 |

### 2.2 召回过场

首张完整过场在 1800ms 完成稀有度落定并进入主动回忆：

| 阶段 | 时间窗 | 内容 |
| --- | --- | --- |
| 起势 | 0–150ms | 卡叠轻压蓄力，IP1 转头，倾斜 ≤ ±4° |
| 靠近取卡 | 150–360ms | IP1 靠近文件夹并开始取出调度器已经选定的旧内容卡 |
| 毛线光迹 | 360–1180ms | 卡片升起；轨迹、卡背和角色动作保持中性，不显示 R / SR / SSR 专属颜色、材质或文案 |
| settle 落定 | 1180–1550ms | 卡面归正，卡框、等级材质、稀有度徽标与掌握状态第一次共同揭晓并落定 |
| 进入回忆 | 1550–1800ms | 主动回忆提示出现；任意时刻可点“跳过过场”直接落地 |

用户在检查点选择继续后，后续卡使用约 900ms 的短过场，只保留 IP1 取卡、卡面升起、停稳和提示；不重复完整光迹仪式。

红线：settle 前不得通过颜色、材质、文字、音效或 VoiceOver 提前泄露稀有度；过场中不出现转盘、卡包、十连、概率数字、保底计数或“差点抽到”的伪悬念。

### 2.3 语义揭示

| 动作 | 参数 |
| --- | --- |
| 语义刮开 / 擦开 | 首次唤醒时，承重语义 span 被铅笔涂鸦层覆盖；使用固定 26pt 自由路径笔刷，覆盖网格达到 45% 后完整揭示，无像素残留 |
| 点击揭示 | 轻点遮盖区域直接完整揭示；键盘 Enter / Space 等价，方向键可分段擦开 |
| 直接揭示 | 始终保留文字按钮与 VoiceOver 自定义动作，服务运动、视觉和认知障碍用户 |
| 复现变式 | 后续复现改为判断（对 / 不对）或选择（少量选项），选择后立即给出对错与解释 |

卡面轻点、自由路径刮开、文字按钮和 VoiceOver 自定义动作必须进入同一个 `revealed` 状态；揭示前只暴露线索与操作提示，揭示后才提供完整答案。

### 2.4 反馈与入册

| 动作 | 参数 |
| --- | --- |
| 三档反馈 | 只有“记得 / 模糊 / 忘记”三个按钮，配色克制（柔绿 / 暖金 / 灰红），无连击、无爆闪 |
| 毛球点击反应 | 点击毛球触发一次 280–420ms 的挤压回弹（squash & stretch），可伴随一句轮换提示 |
| 修复结算 / 入册 | 反馈保存后卡片修复上色，展示掌握状态与真实下次复习时间，再由毛球收回；一次完成，庆祝只此一次，不循环播放 |
| 下次复习 | 反馈真实写入调度并展示：忘记 → 明天优先，模糊 → 2 天后，记得 → 4 天后（演示数值，正式由调度器决定） |
| 检查点 | 当前卡收好后露出下一张真实卡边缘；用户选择“继续召回”或“先收好”，系统不自动连播 |

### 2.5 无假进度

- 禁止假进度条、假百分比、伪造的“加载中”动画；
- 分析等待页只展示真实阶段文案（如“识别画面与文字证据…”）或静态说明；
- 所有等待都必须可被真实完成或真实失败终止。

## 3. 状态机

### 3.1 召回会话状态机

```text
                ┌─────────────┐
                │    home     │ 今日 Tab：单一召回入口
                └──────┬──────┘
              点击 / 上拖 24–36pt
                       ▼
                ┌─────────────┐   跳过 / Reduce Motion
                │  summoning  │ ──────────────────────┐
                └──────┬──────┘                       │
              1800ms 稀有度落定                        │
                       ▼                              ▼
                ┌─────────────┐                ┌─────────────┐
                │   recall    │ ◄──────────────│  (直达卡面)  │
                │ masked /    │                └─────────────┘
                │ judgment /  │
                │ choice      │
                └──────┬──────┘
        擦开 ≥45% / 点击揭示 / 直接揭示 / 作答变式
                       ▼
                ┌─────────────┐
                │  revealed   │ 完整语义 + 解释 + 来源证据
                └──────┬──────┘
            记得 / 模糊 / 忘记
                       ▼
                ┌─────────────┐
                │  assessing  │ 保存反馈与调度信号
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │  repairing  │ 修复卡面 + 掌握状态 + 真实下次时间
                └──────┬──────┘
                       ▼
                ┌─────────────┐
                │ checkpoint  │ 下一张边缘 + 继续召回 / 先收好
                └─────────────┘
                    │       │
                 继续       收好
                    ▼       ▼
              summoning   stowing → home
```

任意时刻退出：持久化当前卡、稳定阶段、刮开覆盖率和反馈标识；下次恢复时不重复提交结果，也不重新播放完整抽取。`judgment` / `choice` 变式只在卡片已完成首次唤醒后出现；`masked_semantic` 只出现一次。

## 4. Reduce Motion 降级

触发源：`prefers-reduced-motion: reduce` 媒体查询（跟随系统，演示页在我的 Tab 中展示当前状态）。

| 标准行为 | 降级行为 |
| --- | --- |
| 1800ms / 900ms 召回过场 | 180ms 缩放与淡入，直接落在回忆卡面 |
| 入口与检查点弹性回弹 | 仅透明度 / 选中态变化，无旋转位移 |
| 上拖手势倾斜 | 保留手势阈值，取消倾斜动画 |
| 擦开粒子 / 涂鸦剥落 | 遮盖层直接淡出，阈值逻辑不变 |
| 毛球 280–420ms 轻回应 | 同一 `IP1-1.svg` 直接落在静态状态位置，无缩放动画 |
| 光迹扫过 | 稀有度徽标直接呈现 |
| 全局滚动与转场 | `animation-duration` / `transition-duration` 收敛到接近 0 |

降级只移除“动”，不移除“态”：状态推进、阈值、结果页和调度完全一样。

## 5. 角色姿态（毛球）

毛球是用户的情境伙伴：奶油白毛发、珊瑚色微光、深青色铅笔描边与轻颗粒阴影。它不发放奖励，只通过姿态解释当前发生的认知动作。本轮不新增中文或英文角色专名；用户界面继续使用“记忆伙伴”或“它”。

主闭环映射固定为：取卡 `turning → rummaging → carrying`；回忆 `watching`；反馈“记得 / 模糊”使用 `acknowledging`、“忘记”使用 `thinking`；收卡使用 `farewell`。这些状态解释用户操作，不组成奖励等级。

| 姿态 | 使用场景 | 表现 |
| --- | --- | --- |
| `idle` | 今日默认 | 同一角色轻微呼吸或上下浮动；每 8–14 秒最多一次 |
| `reacting` | 用户轻点毛球 | 280–420ms 等比放大、轻位移和小角度旋转后回位，不发奖励 |
| `turning` | 开始召回 | 向文件夹方向轻移并旋转，不通过镜像改变朝向 |
| `rummaging` | 选卡阶段 | 角色靠近文件夹，以短距离往返和轻旋转表达翻找；动作可被跳过 |
| `carrying` | 卡片升起 | 角色与代码原生卡片共同位移、轻抬后分离 |
| `watching` | 用户主动回忆 | 安静停留；停顿较久后只做一次轻微位移，不催促 |
| `acknowledging` | 反馈为记得 / 模糊 | 一次小跳或轻侧倾，只播放一次 |
| `thinking` | 反馈为忘记 / 内容处理中 | 下沉、略缩小并轻侧倾，不用惩罚色 |
| `sleeping` | 无可召回内容 / 低频夜间状态 | 略缩小、下沉并极慢呼吸 |
| `farewell` | 用户选择先收好 | 角色随收卡方向轻移、轻旋转后停稳 |

实现约束：开屏和所有宠物位必须使用 `Pick The Shell/IP1-1.svg` 官方毛球，并按 `reuse_as_is` 处理。允许的角色变化只有尺寸 / 裁切、等比缩放、位移、轻旋转与时间节奏；SwiftUI / CSS 负责把同一角色组合到代码原生卡片、文件夹和场景中。不得镜像、非等比变形、切换旧 `RecalloMascot*` PNG、重新生成、重绘或替换该角色。其他非毛球宠物层或临时占位动物必须替换。

## 6. 反赌博与无社交边界

动效与素材不得越过以下边界：

1. 不制造概率悬念：光迹只表达已定卡片的内容潜力，卡在进入过场前已被调度器选定；首页不展示卡池、单抽 / 连续双入口、1/10 或剩余张数；
2. 不用递增刺激：没有连抽加速、没有“再来一发”式催促，每张之间都由用户在检查点手动推进；
3. 不用损失厌恶：没有倒计时、 streak、保底、错过提示；忘记不降级、不摧毁卡片；
4. 不做社交比较：无排行榜、无分享战绩、无好友资产展示；知识库与收藏册仅自己可见；
5. 不用成就压迫：无签到、无每日任务墙；统计页只展示真实数字；
6. 不用虚假反馈：无假进度、无伪装的“AI 正在努力思考”循环动画；
7. 庆祝克制：单次、短促、可跳过，永远服务“我想起来了”这个认知时刻，而不是“我抽到了什么”。

## 8. 旧流程迁移与 MVP 动效验收

### 8.1 旧 MCQ 流程

- 旧 MCQ 唤醒入口从今日页和正式导航中下线，不与新的召回主链并存；
- 历史选择题内容只在卡片完成首次 `masked_semantic` 唤醒后适配为 `choice` 复现任务；
- 旧页面在数据迁移和回归完成前可以保留代码，但只能由开发开关访问，不属于发布构建或 MVP 演示；
- 任何出现卡池预选、单抽 / 连续选择、1/10 进度或自动“下一题”的界面都判定为旧流程回归。

### 8.2 MVP 验收清单

- 今日首页只有一个召回动作：上拖卡叠或点击等价按钮进入同一 `summoning`；
- 今日页前景记忆卡使用不透明实底，后层卡叠不得透过前景卡与文字重叠；
- IP1 按取卡 / 回忆 / 反馈 / 收卡映射进入对应状态；本轮不新增角色专名；
- 首张完整过场为 1800ms；settle 前不泄露稀有度，settle 时 R / SR / SSR 才落定并进入主动回忆；
