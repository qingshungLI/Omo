单元总结

单元完成

多Agent通信的核心问题在于协调而非能力，信息丢失和上下文断裂是常见失败原因。

2. 通信拓扑：中心化 vs 接力

短版中心化模式（主Agent调度）可控、好调试；接力模式灵活但易出问题。

长版通信拓扑决定谁跟谁通信。中心化模式：一个主Agent居中调度，所有子Agent只与主Agent通信，路径清晰，全局状态统一维护，可控、好调试、好观测。接力模式：Agent之间直接传递，更灵活但交接点易出问题。真实项目优先选中心化编排。
