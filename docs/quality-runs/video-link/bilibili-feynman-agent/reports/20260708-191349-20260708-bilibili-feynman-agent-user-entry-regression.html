1. Workflow与Agent的本质区别

短版Workflow是预设步骤，Agent自主决策执行路径。

长版Workflow由人提前设计好每一步，AI按固定路线执行，即使有100个节点也不叫Agent。Agent则像黑盒，自己思考、决定下一步行动，例如面对同一任务，Agent会尝试连接日历、会议工具，甚至主动询问用户，而非按固定流程走。

概要页Workflow和Agent听起来很像，但本质不同。Workflow是预设好的固定步骤，而Agent能自主决策。理解这个区别，是掌握Agent概念的第一步。

3. Agent Loop：自主推理与行动循环

短版Agent Loop是推理→行动→检查→迭代的自主循环。

长版Agent Loop的核心是ReAct框架（Reasoning+Acting）。Agent先思考如何完成任务，然后采取行动（如搜索网页、整理数据、画图），之后自己检查结果是否满意，满意则输出，不满意则继续循环改进。这种自我检查与迭代能力，是Agent区别于普通LLM应用的关键。

概要页Agent Loop是智能体的核心循环：推理→行动→检查→迭代。正是这种自我改进的能力，让Agent区别于普通应用。
