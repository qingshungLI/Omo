R Recallo · iOS MVP

把刷过的内容，变成会再次想起的记忆。

这是当前 iOS 方向的 Web 交互预览。你可以从自己的过去选择记忆池，体验召回、主动回忆、修复与入册。

  1. 1点击手机底部的 +，选择自己的截图，或载入内置 B站演示截图。
  2. 2选择“今日待唤醒 / 时间胶囊 / 快要遗忘”，召回一定来自自己的内容。
  3. 3先回忆再揭晓；R/SR/SSR 表示内容价值，封存到铭刻表示你的掌握程度。
  4. 4向右拖动卡片上的控制条，主动回忆后再看答案，最后进行自评。
Web 页只演示产品交互，不会上传图片或调用模型；正式 iOS 流程由 Qwen 视觉模型分析内容。
