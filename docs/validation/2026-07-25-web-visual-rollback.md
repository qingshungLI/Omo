# Recallo Web 视觉回退与抽卡节奏验证

验证日期：2026-07-25
执行环境：`bridge-amax:/data1/yuxiao/recallo-v064-integration`

## 变更边界

- 只回退 Web 呈现层的视觉密度与构图，不回退真实截图上传、服务端记忆卡、复习调度、删除和失败态。
- 首页恢复大留白、小毛球、卡叠与单一主动作。
- 截图分析完成后不提前展示稀有度、理由和来源，先进入“取回这张”的低压力入口。
- 首张召回从 1450ms 调整为 1800ms，后续召回从 700ms 调整为 900ms。
- Reduce Motion 保持 180ms。
- Web 的 CSS 动画时长改由同一状态值驱动，避免后续卡的 JavaScript 计时与 CSS 动画不同步。

## 视觉对照

| 观察点 | 回退前 | 本次结果 |
| --- | --- | --- |
| 信息密度 | 首页与生成完成页同时出现多段解释和双按钮 | 首页与生成完成页只保留一个标题、一句辅助文案和一个主动作 |
| 角色占比 | 毛球偏大，和卡片争夺视觉中心 | 毛球回到 126pt，并作为轻量陪伴元素 |
| 卡叠 | 高度 225pt，卡层较紧 | 恢复 270pt 纸卡比例与更松的错层 |
| 背景 | 单层平涂、颗粒较弱 | 恢复柔和径向光和可见但克制的纸张颗粒 |
| 顶栏 | 17pt 标题、透明加号 | 14pt 小标题与纸面圆形加号 |
| 主路径 | 生成完成后直接暴露答案线索和多个决策 | 先保留悬念，再由用户主动取回 |

375×812 的空状态截图确认：标题、毛球、卡叠、主按钮和三栏导航均在首屏内，无水平溢出。

## 动画验证

- Web 首次召回状态值：1800ms。
- Web 浏览器实测从点击到进入回忆页约 1904ms，包含浏览器自动化点击和渲染开销。
- iOS 首次阶段数组总计：1800ms。
- iOS 后续阶段数组总计：900ms。
- Web CSS 通过 `--summon-duration` 使用同一状态值，光迹通过 `--orbit-duration` 随过场缩放。
- “跳过”仍会立即取消过场并进入主动回忆。
