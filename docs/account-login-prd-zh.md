# Recallo 账号登录首版 PRD

## 目标

首版账号系统服务于 TestFlight 和 App Store 审核：用户可以不登录直接使用；需要跨设备、恢复数据或满足平台账号要求时，可以选择使用 Apple 登录。账号功能不应阻塞核心体验，也不应让匿名用户感到被迫注册。

## 匿名到账号的演进路线

当前“可选 Apple 登录 + 匿名可用”是首版降低试用门槛的过渡方案，不代表匿名会长期作为正式用户身份。Recallo 会长期保存章节、收藏、学习进度、头像和通知等个人资产，因此匿名模式必须被设计成可迁移、可收口的临时身份。

| 阶段 | 产品策略 | 工程要求 |
| --- | --- | --- |
| v1.0 | 可选 Sign in with Apple + 匿名可用，但强烈引导绑定账号 | 登录时把当前设备上的章节、收藏、学习进度、通知、生成记录绑定到 Apple 账号；文案明确匿名数据恢复边界 |
| v1.1 / v1.2 | 在高价值动作前提示绑定，例如生成第二篇真实 AI 文章、收藏、跨设备恢复、长期学习记录 | 保持推荐好文和首次体验低摩擦；增加迁移提示和绑定完成后的数据刷新 |
| v2.0 | 新用户默认使用 Apple 登录后进入完整功能；老匿名用户首次打开先迁移 | 完成匿名数据到账号的数据绑定；迁移后再进入主页；失败时给出可恢复的重试路径 |
| 兼容期 | 后端继续兼容匿名请求 1-2 个版本周期 | 避免旧 App 版本和未迁移用户突然失效；监控匿名写入量后逐步收紧匿名能力 |

关闭匿名主路径前必须完成：迁移提示、迁移接口、迁移回归测试、旧版本兼容策略、隐私政策更新、账号说明更新和 App Review 说明更新。

## 首版范围

- 支持匿名使用。
- 支持可选 Sign in with Apple。
- Apple 登录后，将当前设备上的章节、收藏、通知、生成额度、推送 token 绑定到账号。
- 登录后真实 AI 生成额度按账号优先统计；未登录时按设备统计。
- 支持删除账号，删除账号关联的业务数据，并回到匿名模式继续使用。
- 首版不做微信登录。
- 首版不做 IAP / 订阅。

## 入口与文案

入口放在个人主页的账号说明 / 账号设置区域。

匿名状态：

- 主标题：当前为匿名模式
- 说明：你可以直接使用 Recallo。登录 Apple 账号后，可以把当前设备上的学习数据绑定到账号。
- 主操作：使用 Apple 登录

已登录状态：

- 主标题：已绑定 Apple 账号
- 说明：学习记录、收藏、通知和生成额度已绑定到当前账号。
- 辅助信息：显示账号 ID 后 8 位，避免展示邮箱等敏感信息。
- 危险操作：删除账号

## 数据绑定规则

### 匿名到 Apple 账号

用户第一次 Apple 登录时：

1. 后端验证 Apple identity token。
2. 基于 Apple `sub` 的哈希查找或创建账号。
3. 当前 `deviceId` 与账号建立绑定。
4. 当前设备已有的章节、收藏、通知、生成任务、推送 token 绑定到该账号。
5. 前端刷新全局数据。

### 重复登录

同一个 Apple 账号再次登录：

- 复用同一个账号。
- 当前设备建立或刷新绑定。
- 当前设备的新匿名数据绑定到该账号。

### 数据读取

当前首版仍以设备数据读取为主，登录后写入 `account_id`，为后续跨设备同步打基础。下一阶段如果要做真正跨设备恢复，需要把读取路径升级为“账号优先，设备兜底”。

## 删除账号规则

用户删除账号时：

- 软删除账号。
- 删除或软删除账号关联的章节、收藏、通知、生成任务、额度记录、推送 token。
- 写入 `account_deletion_jobs` 和 audit event。
- 前端清空账号状态，回到匿名模式。

不删除：

- 服务器运行日志。
- 已匿名化或聚合统计数据。
- 与账号无关的推荐好文池。

## Apple 合规待办

当前代码已完成 identity token 验证和账号绑定。App Store 生产级删除闭环还需要补齐 Apple token revoke：

1. Apple Developer 后台为 `com.maxhan.shibei` 开启 Sign in with Apple capability。
2. 创建 Sign in with Apple private key。
3. 配置后端环境变量：Team ID、Key ID、private key、client id。
4. 后端使用 iOS 传来的 `authorizationCode` exchange refresh token。
5. 删除账号时调用 Apple revoke token API。

在以上配置完成前，账号数据可以删除，但 Apple token revoke 状态只能标记为 `not_configured`。

## 验收标准

- 匿名用户可继续完整生成、学习、收藏。
- Apple 登录取消不会报错或卡住。
- Apple 登录成功后，个人主页显示已绑定状态。
- Apple 登录成功后，刷新章节/通知/收藏不丢数据。
- 登录后额度按账号计数；匿名按设备计数。
- 删除账号后账号状态清空，旧账号数据不再可见。
- 删除账号后匿名模式仍可继续使用。
- 真机 Archive 前，Xcode 签名 profile 必须包含 Sign in with Apple entitlement。
