# App Store Checkpoint Status Reconciliation

Date: 2026-07-03
Scope: `docs/app-store-release-readiness-plan-zh.md`

## Purpose

The plan had two layers:

- Section 3 and Task 1-10 contained the current detailed readiness status.
- Section 5 still contained early checkpoint bullets, so several already-completed Codex-owned items appeared unfinished again.

This reconciliation updates Section 5 to match the evidence already produced by Task 1-10 and the release guard scripts.

## Updated As Complete

- Checkpoint 1: plan status, Release/Archive configuration review, and App Review checklist outputs.
- Checkpoint 2: account/data recovery flow design, account deletion scope design, privacy/review-note draft updates.
- Checkpoint 3: daily quota design and implementation, recommended-content quota policy, quota error code and UX copy.
- Checkpoint 4: Recallo privacy policy update, App Privacy label draft, in-app privacy/account/notification copy review, data deletion/logging governance notes.
- Checkpoint 5: metadata draft, Review Notes draft, age rating draft.
- Checkpoint 6: automated production health gate for Railway health, queue, APNs, and error status.
- Checkpoint 7: Review Notes preparation, while keeping App Store Connect submission steps user-owned.

## Intentionally Still Open

These are not marked complete because they require user-owned decisions, App Store Connect access, true-device validation, or public URLs:

- App Store Connect current configuration.
- Apple Developer capabilities, including the final Sign in with Apple decision.
- Support URL and Privacy Policy URL.
- Official App Store screenshots.
- Real-device production acceptance.
- Xcode Archive and App Store Connect upload/submission.
