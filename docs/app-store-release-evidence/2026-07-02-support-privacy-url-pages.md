# Support URL / Privacy URL 页面准备记录

日期：2026-07-02

## 本次完成

- 新增 `docs/support.html`，作为 App Store Support URL 的静态页面草案。
- 新增 `docs/support-zh.md`，作为支持页可编辑中文草案。
- 新增 `docs/app-store-url-publishing-guide-zh.md`，说明 Privacy URL 和 Support URL 的发布方式、用户需要提供的信息和提交前检查。
- 更新 `docs/app-store-metadata-zh.md` 和 `docs/app-store-user-action-checklist-zh.md`，把 URL 状态从“未准备”改为“页面已准备，待部署公开 URL”。

## 仍需用户完成

- 提供正式对外支持邮箱。
- 选择页面托管方式。
- 提供最终公开 HTTPS URL：
  - Privacy Policy URL
  - Support URL

## 提交审核前停止条件

- `docs/support.html` 中仍出现“待补充”时，不应提交 App Store 审核。
- `docs/privacy-policy.html` 中仍出现“邮箱：待补充”时，不应提交 App Store 审核。
- App Store Connect 中填写的 URL 无法未登录访问时，不应提交 App Store 审核。
